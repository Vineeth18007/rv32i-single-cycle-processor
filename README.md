# rv32i-single-cycle-processor
# Design and Simulation of a 32-bit RV32I Single-Cycle RISC-V Processor

## Overview
An ongoing project to implement and simulate a 32-bit single-cycle RISC-V processor using SystemVerilog and Questa/QuestaSim.

## Architecture
The processor datapath is being developed using the following modules:
- Program Counter and PC+4 logic
- Instruction Memory
- Register File
- Immediate Generator
- ALU and ALU Control
- Main Control Unit
- Data Memory
- Branch and next-PC selection logic

## Tools
- SystemVerilog
- Questa/QuestaSim
